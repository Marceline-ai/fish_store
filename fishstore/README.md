# FishStore Manager

Система автоматизации учёта товародвижения для ИП «Горлов Н.С.»

## Требования

- Python 3.8+
- PostgreSQL 12+
- PyQt5

## Установка

1. Создайте виртуальное окружение:
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте файл `.env`:
```bash
cp .env.example .env
# Отредактируйте .env с вашими параметрами подключения к БД
```

4. Создайте базу данных (выполните SQL скрипт из документации)

5. Запустите приложение:
```bash
python main.py
```

## Роли пользователей

- **admin** - полный доступ ко всем функциям
- **manager** - управление товарами, поставщиками, продажами, списаниями
- **cashier** - только регистрация продаж и просмотр остатков

## Функциональность

- ✅ Управление справочниками (товары, поставщики, пользователи)
- ✅ Регистрация поступлений партий
- ✅ Регистрация продаж с проверкой остатков
- ✅ Регистрация списаний
- ✅ Контроль сроков годности
- ✅ Отчётность (продажи, списания, инвентаризация)
- ✅ Экспорт отчётов в CSV
- ✅ Ролевая модель доступа
- ✅ Логирование действий

## Безопасность

- Параметризированные SQL запросы (защита от инъекций)
- Хэширование паролей (bcrypt)
- Конфигурация через .env файл
- Транзакционная целостность (ACID)
